# Routine Manager

Mobile routine planner (Expo React Native + Node.js + MongoDB + OpenAI). Speak or type your day plan; the app builds calendar reminders and sends notifications.

## Start here

All requirements, architecture, schemas, and the step-by-step build order live in:

**[IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md)**

Work through features in checklist order. Do not skip ahead until the current feature’s acceptance tests pass.

## Stack (summary)

| Layer | Choice |
| --- | --- |
| Mobile | Expo + Expo Router |
| Backend | Node.js + Express |
| Database | MongoDB Atlas |
| AI | OpenAI (tools + Whisper) |
| Backend host | Render Free |
| Mobile previews | Expo Go / EAS Update |
